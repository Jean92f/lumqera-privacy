Política de Privacidad

CARTERA — Tus cobros, bajo control
Última actualización: 30 de septiembre de 2026

Esta Política de Privacidad explica cómo CARTERA, desarrollada por Lumqera Labs, accede, utiliza, almacena y permite compartir determinada información cuando utilizas la aplicación.

CARTERA funciona principalmente de forma local. La información comercial registrada en la aplicación se almacena en el dispositivo del usuario. Lumqera Labs no opera actualmente un servidor propio para almacenar o sincronizar esta información.

1. Información almacenada en CARTERA

CARTERA permite al usuario registrar información necesaria para administrar sus cuentas por cobrar. Esta puede incluir:

  • Nombre o razón social de clientes.
  • Tipo y número de documento.
  • Teléfono, correo electrónico y dirección.
  • Notas introducidas por el usuario.
  • Conceptos e importes de cuentas por cobrar.
  • Fechas de emisión y vencimiento.
  • Pagos y abonos registrados.
  • Reprogramaciones de vencimientos.
  • Información del perfil del negocio.
  • Logotipo del negocio seleccionado por el usuario.

Esta información se almacena localmente en el dispositivo. CARTERA no proporciona actualmente sincronización propia de estos datos con servidores de Lumqera Labs.

2. Acceso a contactos

CARTERA puede solicitar permiso para acceder a los contactos del dispositivo. Esta función es opcional y se utiliza únicamente cuando el usuario selecciona expresamente la opción para elegir un contacto.

Al utilizar esta función, CARTERA obtiene del contacto seleccionado su nombre y número telefónico para facilitar el registro de un cliente. Estos datos solo se guardan en CARTERA si el usuario decide guardar el cliente.

CARTERA no escanea automáticamente toda la agenda de contactos ni envía la agenda a servidores de Lumqera Labs.

3. Notificaciones

CARTERA puede solicitar permiso para mostrar notificaciones relacionadas con recordatorios de cobros y vencimientos.

Estos recordatorios se calculan y programan localmente en el dispositivo. CARTERA no utiliza actualmente Firebase Cloud Messaging ni otro servicio propio de notificaciones push remotas.

4. WhatsApp y aplicaciones externas

CARTERA permite preparar un mensaje relacionado con una cuenta por cobrar y abrir WhatsApp cuando el usuario solicita expresamente esta acción.

Dependiendo de la información registrada, el mensaje puede incluir:

  • Número telefónico del cliente.
  • Nombre del cliente.
  • Saldo pendiente.
  • Concepto de la cuenta.
  • Fecha de vencimiento.

CARTERA no envía mensajes de WhatsApp automáticamente. El usuario inicia la acción y conserva el control sobre el envío.

Cuando el usuario decide compartir información con una aplicación externa, el tratamiento posterior de esa información queda sujeto a los términos y políticas de privacidad del servicio seleccionado.

5. Generación y compartición de documentos PDF

CARTERA puede generar documentos PDF, como estados de cuenta o comprobantes, en el dispositivo.

CARTERA no carga estos documentos a servidores propios de Lumqera Labs. Cuando el usuario selecciona la opción para compartir un documento, se utiliza el mecanismo de compartición del sistema Android para que el propio usuario seleccione la aplicación o destinatario.

Determinados recursos tipográficos utilizados para generar documentos pueden obtenerse mediante servicios de Google Fonts cuando sean necesarios.

6. CARTERA Pro y Google Play

CARTERA puede ofrecer funciones Pro mediante suscripciones procesadas por Google Play.

Google Play procesa la información necesaria para realizar y administrar estas compras. CARTERA no recibe ni almacena números de tarjetas de crédito o débito ni credenciales bancarias utilizadas para efectuar el pago.

CARTERA puede recibir de Google Play información técnica relacionada con el estado de una compra o suscripción para determinar si las funciones Pro están disponibles.

El procesamiento realizado por Google está sujeto a sus propios términos y políticas de privacidad.

7. Analítica, seguimiento y publicidad

La versión actual de CARTERA no integra SDK de publicidad ni servicios propios destinados a realizar seguimiento publicitario del usuario.

Actualmente CARTERA tampoco integra Firebase Analytics, Google Analytics, Firebase Crashlytics, Sentry, Mixpanel, Amplitude ni Facebook SDK.

8. Almacenamiento y copias de seguridad

La base de datos comercial de CARTERA se mantiene en el almacenamiento local privado de la aplicación.

CARTERA no ofrece actualmente sincronización propia en la nube. La copia de seguridad automática de Android para los datos de la aplicación se encuentra deshabilitada en la versión actual.

9. Eliminación de información

CARTERA proporciona funciones para desactivar clientes y cancelar cuentas por cobrar dentro de la aplicación.

Para eliminar todos los datos almacenados localmente por CARTERA, el usuario puede borrar los datos de almacenamiento de la aplicación desde la configuración de Android o desinstalar CARTERA del dispositivo.

Debido a que Lumqera Labs no mantiene actualmente cuentas remotas ni una base de datos propia en la nube para CARTERA, no existe una cuenta remota del usuario que deba solicitarse eliminar a Lumqera Labs.

10. Seguridad

CARTERA utiliza una arquitectura principalmente local con el objetivo de limitar la transmisión innecesaria de información comercial.

Sin embargo, ningún sistema de almacenamiento o procesamiento de información puede garantizar una seguridad absoluta.

11. Información que CARTERA no solicita

La versión actual de CARTERA no solicita directamente:

  • Ubicación GPS.
  • Acceso a cámara.
  • Acceso a micrófono.
  • Datos biométricos.
  • Contraseñas de cuentas CARTERA.
  • Números de tarjetas bancarias para procesar suscripciones.
  • Identificadores publicitarios para publicidad personalizada.

12. Menores de edad

CARTERA es una herramienta destinada a la gestión de negocios y cuentas por cobrar y no está diseñada específicamente para niños.

13. Servicios de terceros

Algunas funcionalidades pueden interactuar con servicios o aplicaciones de terceros cuando el usuario lo solicita, entre ellos Google Play, WhatsApp y las aplicaciones seleccionadas mediante el menú de compartición de Android.

El uso de dichos servicios puede estar sujeto a sus propias políticas y condiciones.

14. Cambios en esta Política de Privacidad

Lumqera Labs puede actualizar esta Política de Privacidad cuando cambien las funcionalidades de CARTERA, los servicios utilizados, las obligaciones aplicables o las prácticas relacionadas con el tratamiento de información.

Cuando se realicen cambios, se actualizará la fecha indicada al comienzo de esta página.
